# 文書・コミット運用ルール

このリポジトリでは、公開面に出る文章を日本語で統一します。

## 基本方針

- README は日本語で書く
- コミットメッセージも日本語で書く
- GitHub 上で最初に読む文書は、できるだけ簡潔に整理する

## README の方針

- まず概要を書く
- 次に何ができるかを書く
- 最後に使い方や関連ドキュメントへ誘導する
- 運用メモをそのまま貼るのではなく、公開向けに整える

## コミットメッセージの方針

日本語で、何を変えたかが一目で分かる表現を使う。

例:

- `translator の README を日本語に整理`
- `portfolio 用の projects 構成を追加`
- `翻訳プレビュー生成の不具合を修正`
- `job_runner の blocked 表示を改善`

避けたい例:

- `update`
- `fix`
- `misc`
- `いろいろ`
